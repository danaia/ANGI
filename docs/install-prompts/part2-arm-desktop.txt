INSTALL ANGI, PART 2: get my ANGI system ready. The target is my ARM computer. The card from part 1 is in it and it is connected to this computer.
Explain each step in one short, plain sentence. Do the terminal work yourself and
guide me through it: before each step say what you are about to do and what I will
see, tell me exactly when I need to do something physical, and wait for me. Ask me
only for passwords, approvals, or something physical.

Repository: https://github.com/danaia/ANGI.git (use the checkout from part 1 if
there is one; otherwise clone it).

STEP 0 - TARGET
I am installing ANGI on: ARM computer (BOARD=arm-desktop). Do not ask me which one.
Run python3 scripts/detect-board.py --require arm-desktop. If it reports no build, stop
and tell me. If it reports an experimental build, explain what remains unverified
and ask whether I want to proceed.

STEP 1 - SET UP THE LINK
There is no cable profile for this target. Ask me how it is reachable (it is on my network,
or I have its screen and keyboard) and help me connect that way.

STEP 2 - FIND IT
Wait for it to start from the drive. Help me find its address (ask me, or check my router
or the screen) and confirm I can reach it. If it does not start, help me find the boot menu
key and choose the drive.

STEP 3 - CONNECT SAFELY
Connect as root@ADDRESS with my private key. This is a new system, so show me the
SSH fingerprint before trusting it, and ask me before replacing any old saved key
for that address. Run agx status --json to confirm it is ANGI, and run
scripts/detect-board.py --identify root@ADDRESS to confirm it is the target I chose.
If it is a different one, stop and tell me.

STEP 4 - JOIN WI-FI (REQUIRED: the most important step)
ANGI must be on Wi-Fi so it can reach the web. Do not call the install done until this
works. The cable only carries this setup; Wi-Fi carries the internet.
1. Ask me for my Wi-Fi network name, its security (WPA2 is the usual one) and my
   two-letter country code, if I have not given them. Never ask me to paste the
   password into this chat and never put it in a command line or a log.
2. On the system run: agx wifi country CODE, then agx wifi scan --json, and confirm my
   network is listed. If it is not, tell me and help me fix it (distance, band, name).
3. Run ssh -t ... agx wifi connect "NETWORK" --security wpa2 (add --hidden for a hidden
   network). It asks for the password with the screen echo off: tell me to type it
   there. (Or open agx tui and use the Network tab, key 4.)
4. Verify: agx wifi status --json shows it connected with an IP address, and
   agx wifi check shows DNS and HTTPS work. Show me the result.
5. If it fails, diagnose: wrong password, wrong country code, a band the hardware does
   not support, or a captive-portal network (those are not supported). Try again with me.
6. Offer to reboot it (F10 in agx tui) and confirm it joins Wi-Fi again by itself.

STEP 5 - GET THE REST OF THE SYSTEM READY
Open agx tui in an interactive SSH terminal if you can (otherwise give me one exact
command, with the key path). Walk me through, one at a time, waiting for me:
1. Explain keys 1-7, ?, F9, F10 and q.
2. Profile tab: set up my account and password login.
3. Services and Logs: run agx services --json and show me everything is healthy.

STEP 6 - FINISH
Tell me how to shut down safely (F9) and how to reconnect later (over the cable, or over
Wi-Fi at the address shown in Network). Report what you checked, confirm Wi-Fi is
connected, and say what is still unresolved.
