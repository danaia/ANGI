Build your own OS

Choose your hardware and copy its build prompt into your coding agent. Your agent builds ANGI locally and guides you through first boot.

Questions

My agent cannot run the prompt

Use an agent that can run commands on your computer, such as Claude Code, Codex, Cursor's agent mode or OpenCode. The agent needs access to a local Linux build environment and direct access to the media you plan to write.

The agent cannot find my card

Take the card out and put it back in, then ask the agent to look again. Tell it the card's size and your card reader's model if it still cannot tell which disk it is.

The agent cannot connect to my Pi

Give the Pi time to boot, then check power and use a cable that carries data. Your agent can check the route and verify the Pi’s identity.

The Pi keeps restarting

Your computer's USB port may not supply enough power. Try another port, a powered USB hub, or a shorter, better cable.

My Wi-Fi network is not listed

Check the country you chose, then scan again in the ANGI terminal dashboard. Use manual entry for a hidden network.

Which target do I pick for a Pi 400?

Choose Pi 4. The Pi 4 and Pi 400 share a build configuration.

Does the image include my passwords or keys?

You create your administrator account and join Wi-Fi after first boot. A locally prepared image can include your SSH public key. Your workstation private key stays on your computer.

Will writing the image erase my card?

Yes. Your agent shows you the card first and erases nothing until you type erase followed by the card's exact device path.

How does the agent check the image?

The agent checks the local build against the selected hardware, verifies its checksum, and compares the written media with the validated image.

Set up? Start building.

Code on the device, or from your computer over USB-C or Ethernet with live updates.
