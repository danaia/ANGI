Code on the device,
or from your computer.

ANGI is an operating system you code with your agents. That's why there is no distro underneath: nothing to inherit, nothing to work around. You are in full control. Build on the device itself, or from your own computer while it runs.

On the device

Everything you need runs on ANGI itself. Describe a task and let the agents build it, or write the code yourself.

  • Run agent angi: an orchestrator, builder and tester work on the board
  • Code editor, terminal, browser and file manager built in
  • One-click apps from the Apps tab, installed per account

From your computer

Connect over USB-C or Ethernet and push updates to the running system from another computer. No reflash, no reboot.

  • Hot reload: a new release loads into the running desktop
  • Rollback guard: the previous release returns if the new one fails
  • Every agx command speaks --json over SSH
